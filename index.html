What's Inside

Everything a Privacy Tool Should Be

Built by engineers who take security seriously. No bloatware, no cloud lock-in, no mystery boxes.

🔀

Reverse-Label Trie Engine

Domain-boundary-safe matching in O(k) time. notexample.com never matches a rule for example.com. Ever.

🔒

Zero Traffic Interception

ShieldNet only evaluates DNS queries — never inspects payloads, decrypts HTTPS, installs certificates, or proxies connections.

⚡

LRU Decision Cache

Thread-safe, TTL-aware LRU cache means frequently queried domains resolve in nanoseconds after the first evaluation.

📋

3 Verified Blocklists

StevenBlack Unified Hosts, AdGuard DNS Filter, and OISD Basic. All downloaded directly from official repositories over HTTPS.

🤖

Auto-Update Engine

Validates content before activating. A failed download falls back to the last cached copy — one broken list never kills your protection.

🧩

Custom Rules & Allowlists

Allow rules unconditionally override block rules. One tap to allowlist a broken domain directly from the live query log.

🪟

Windows Service Integration

Runs as a persistent background service. Backups your adapter DNS before touching anything. Restores it cleanly on shutdown or uninstall.

📱

Android VpnService (No Root)

Routes only DNS traffic through the TUN interface — not your video streams or downloads. Battery-safe by design. No root required.

📊

Live Dashboard & Analytics

Real blocked/allowed counts, per-category breakdowns, query latency, and searchable log — all from on-device data only.

Two Platforms, One Engine

Same Rules. Same Logic. Everywhere.

Windows Desktop — Python + PySide6

Architecture
  • Background daemon on 127.0.0.1:53
  • IPC control socket on 127.0.0.1:49512
  • Adapter DNS redirect via netsh
  • PowerShell-based DNS snapshot & restore
  • Inno Setup distributable installer
GUI Screens
  • Dashboard — live metrics
  • Query Activity — searchable log
  • Blocklists — toggle & refresh
  • Custom Rules — add/remove/export
  • Settings & Diagnostics

Android APK — Kotlin + Jetpack Compose

Architecture
  • Android VpnService TUN interface
  • DNS-only routing (battery-safe)
  • Upstream sockets are protect()'ed
  • No root required
  • WorkManager for background updates
Screens
  • Dashboard — shield status
  • Activity — query log & search
  • Blocklists — enable/disable
  • Custom Rules — add/allow/block
  • Settings — resolver + Private DNS notice
